Colección de algoritmos, pruebas estadísticas y modelos de programación lineal desarrollados en R y Python para la resolución de problemas actuariales, valuación financiera y optimización de recursos.

Análisis Numérico y Optimización (P5 Metodo de Newtoom.rmd): Implementación algorítmica del Método de Newton-Raphson para la aproximación de raíces en funciones no lineales complejas.

Modelado de Distribuciones Continuas (S14_distribuciones_continuas_simulacion.Rmd): Aplicación de funciones de densidad de probabilidad y funciones de distribución acumulada  para variables aleatorias continuas (Uniforme, Exponencial, Gamma, Weibull, Normal y Log-Normal). Incluye simulación de variables aleatorias a través del método de Monte Carlo y visualización de distribuciones empíricas contrastadas con curvas teóricas utilizando R base. 

Análisis Descriptivo y Formas de Distribución (S15_analisis_descriptivo_asimetria_curtosis.Rmd): Evaluación de la forma de distribuciones de datos continuos mediante el análisis exploratorio de datos. Implementación de reglas heurísticas (Sturges, Scott, Freedman-Diaconis) para la optimización de histogramas en ggplot2, y cálculo de momentos estandarizados de orden superior (coeficiente de asimetría de Fisher-Pearson y curtosis) para clasificar distribuciones como leptocúrticas, mesocúrticas o platicúrticas utilizando la librería moments.   

Distribuciones Discretas y Escenarios Actuariales (S16_distribuciones_discretas_actuariales.Rmd): Modelado de variables aleatorias discretas (Binomial, Geométrica, Binomial Negativa y Poisson) aplicadas a escenarios de riesgo, como la probabilidad de reclamaciones de seguros y la detección de fraudes en carteras de clientes. Incluye simulación de caminatas aleatorias (juegos de apuestas) y contrastes gráficos entre frecuencias empíricas y teóricas usando ggplot2.   

Análisis Exploratorio y Curvas de Densidad (S17_analisis_curvas_densidad_eda.Rmd): Estimación suave de distribuciones de probabilidad a través de curvas de densidad empíricas y teóricas. El script incluye el modelado de tiempos de interarribo y análisis de demanda de inventarios, evaluando la idoneidad de los datos frente a distribuciones paramétricas y ajustando visualmente los intervalos mediante las reglas de Sturges, Scott y Freedman-Diaconis.   

Estimación de Parámetros por Máxima Verosimilitud (S18_estimacion_parametros_mle.Rmd): Desarrollo de algoritmos para la estimación de parámetros (MLE) en distribuciones continuas (Exponencial, Weibull, Gamma) y discretas (Geométrica, Poisson, Binomial). Incluye la implementación manual del método de Newton-Raphson para aproximar los parámetros de forma iterativa, y la automatización del ajuste mediante la librería fitdistrplus, utilizando los Criterios de Información de Akaike (AIC) y Bayesiano (BIC) para penalizar la complejidad y seleccionar el mejor modelo.   

Pruebas de Bondad de Ajuste (S_19pruebas_bondad_ajuste.Rmd): Validación estadística rigurosa de modelos probabilísticos. Implementación de pruebas de hipótesis mediante las métricas de Kolmogorov-Smirnov (ks.test) y Anderson-Darling (ad.test). El script automatiza la comparación simultánea de múltiples distribuciones candidatas evaluando las discrepancias absolutas entre las funciones de distribución acumulada (CDF) empíricas y teóricas.
